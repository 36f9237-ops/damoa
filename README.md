# 다모아 AI 서버 연결

기존 다모아 화면과 OpenAlex 검색 기능을 유지하고, Vercel 서버 함수 `/api/chat`를 통해 선택 논문 초록 번역 및 논문 비교 분석을 제공합니다.

## 배포 구조

- `index.html`: 기존 검색·필터·저장·PDF 분석·논문 비교 화면과 AI 요청 UI
- `api/chat.js`: Vercel의 `POST /api/chat` 진입점
- `server/chat.js`: 이용 코드 확인, 요청 검증·크기 제한, 제공사 API 호출, 오류 처리
- `package.json`: ES 모듈 및 Node.js 24 런타임
- `vercel.json`: 정적 화면과 서버 함수 배포 설정
- `.gitignore`: 로컬 비밀 설정 파일 제외

GitHub Pages는 정적 파일만 제공하므로 `/api/chat` 서버 함수를 실행하지 않습니다. Vercel에서 이 저장소를 배포하고, 사용자는 Vercel이 제공하는 HTTPS 주소로 접속해야 실제 AI 기능이 작동합니다.

## Vercel 환경변수

Vercel 프로젝트의 **Settings → Environment Variables**에 등록합니다. 비밀키와 이용 코드를 HTML·GitHub 저장소·브라우저 코드에 넣지 마세요.

필수 항목:

| 이름 | 설정 |
| --- | --- |
| `AI_PROVIDER` | `openai` 또는 `anthropic` 중 하나 |
| `AI_MODEL` | 선택한 제공사에서 실제 사용 권한이 있는 모델 ID |
| `OPENAI_API_KEY` | `AI_PROVIDER=openai`일 때 팀 프로젝트의 API 키 |
| `ANTHROPIC_API_KEY` | `AI_PROVIDER=anthropic`일 때 팀 워크스페이스의 API 키 |
| `CHAT_ACCESS_CODE` | 사용자에게 별도로 안내할 무작위 이용 코드. 영문·숫자·`_`·`-` 16~128자 |

선택 항목:

| 이름 | 기본값·제한 |
| --- | --- |
| `CHAT_SYSTEM_PROMPT` | 생략 시 기본 지침 사용. 최대 4,000자 |
| `MAX_OUTPUT_TOKENS` | 기본 800, 허용 범위 128~1600 |
| `ANTHROPIC_WORKSPACE_ID` | Anthropic 키에 워크스페이스 범위를 지정할 때 사용 |

실제 API 키와 이용 코드는 이 파일이나 공개 대화에 기록하지 마세요. 운영자가 직접 Vercel 환경변수 화면에 입력합니다.

## 적용 순서

1. 이 변경사항을 GitHub `main`에 반영합니다.
2. Vercel에서 **Add New → Project**로 `36f9237-ops/damoa` 저장소를 가져옵니다.
3. Root Directory는 `package.json`, `index.html`, `api/`, `server/`가 있는 저장소 루트로 지정합니다.
4. Framework Preset은 **Other**로 설정합니다. Build Command와 Install Command는 비워 두고 Output Directory는 `.`로 둡니다.
5. 위 환경변수를 운영자가 등록합니다. 제공사·모델·이용 한도는 담당 교사 또는 프로젝트 운영자가 확인합니다.
6. Deploy를 실행합니다. 환경변수를 바꿨다면 Redeploy합니다.
7. Vercel HTTPS 도메인으로 접속해 시험합니다. 기존 GitHub Pages 주소는 서버 함수가 없으므로 실제 AI 호출용 주소로 사용할 수 없습니다.

## AI 기능

- **AI 초록 번역**: 논문 상세 화면에서 현재 논문의 제목·서지 정보·초록을 전송하고 선택한 번역 언어로 번역합니다.
- **AI 관점 비교**: 비교 화면에서 선택된 2~3편의 제목·서지 정보·초록을 전송해 핵심 키워드, 연구 질문, 관점, 연구 방향, 공통점과 차이점을 비교합니다.
- AI 응답은 텍스트로 표시하며 HTML로 실행하지 않습니다. 초록에 없는 정보는 추측하지 않도록 지시합니다.
- 서버 설정 전 초기 상태는 **예시 답변 · 실제 AI 연결 전**으로 표시됩니다.

## 요청 제한 및 안전

- 질문 최대 2,000자, 참고 자료 최대 6,000자, 요청 본문 최대 40,000바이트
- 대화와 자료 합계 최대 12,000자
- 서버에서 이용 코드를 상수 시간 비교 방식으로 확인
- 같은 출처의 HTTPS 요청만 허용
- 중복 클릭 방지, 서버·제공사 대기시간 제한, 오류 메시지 처리
- API 키는 서버 환경변수에서만 읽으며 클라이언트로 반환하지 않음
- 논문 제목·초록 등 선택 자료는 AI 제공사로 전송됨. 공개 가능한 자료만 사용

이 서버 예제는 요청별 검증과 크기 제한을 제공하지만 데이터베이스 기반 사용량 집계나 전체 비용 한도 관리는 하지 않습니다. 공개 체험 전 제공사 콘솔에서 프로젝트 사용량·비용 제한을 별도로 설정하세요.

## 시험 방법

1. 환경변수 설정 전 화면 라벨이 **예시 답변 · 실제 AI 연결 전**인지 확인합니다.
2. 이용 코드 없이 AI 기능을 눌러 코드 안내가 나타나는지 확인합니다.
3. 잘못된 코드로 요청해 서버가 거절하는지 확인합니다.
4. 정상 코드로 논문 상세 화면의 AI 초록 번역을 실행하고 번역 언어별 결과를 확인합니다.
5. 논문 2~3편을 선택해 AI 관점 비교를 실행하고, 각 논문의 제목·초록을 실제 반영하는지 확인합니다.
6. 연속 클릭, 빈 초록, 네트워크 차단, 환경변수 누락 상황에서 중복 요청이 발생하지 않고 오류가 안내되는지 확인합니다.
7. Vercel Functions/Logs와 제공사 사용량 화면에서 요청 및 사용량을 확인합니다. 로그에 비밀키나 이용 코드를 기록하지 마세요.

모델 ID, 제공사 키, 워크스페이스 설정 및 사용 권한은 제공사 계정마다 다르므로 임의로 지정하지 않습니다.
